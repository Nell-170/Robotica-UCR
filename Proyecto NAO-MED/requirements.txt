#   3. Preguntar en tu lab si ya tienen el SDK instalado
#   4. Buscar forks comunitarios en GitHub (buscar "pynaoqi")
#   
#   Una vez descargado, agrégalo al PYTHONPATH o cópialo a la carpeta del proyecto
#
